The idea

Open by default. Useful by design.

The project is a framework for turning an emerging brand into a shared, understandable, and extensible project. The goal is not to have every answer today. The goal is to make it easy to discover the questions, contribute an answer, and improve what comes next.

Contribution

There is more than one way to help.

A healthy open project needs people with different skills and different amounts of time.

Build

Prototype features, fix bugs, improve tooling, create integrations, and make the project easier to run.

Explain

Write guides, improve onboarding, document decisions, create examples, and turn complexity into understandable language.

Support

Welcome newcomers, answer questions, test releases, organize discussions, and help maintain a constructive community.

Accessibility

Design for more people from the start.

This starter site uses semantic HTML, keyboard-accessible controls, visible focus styles, a skip link, responsive layout, readable contrast, and a reduced-motion preference.

Content

Use plain language, descriptive headings, meaningful link text, alt text for informative images, and captions/transcripts for media.

Interaction

Keep controls keyboard accessible, provide visible focus, use real buttons and links, and do not rely on color alone to communicate meaning.

Testing

Test with keyboard-only navigation, browser zoom, high contrast or forced-colors modes, screen readers, and users with different access needs.
